# MD Viewer로 문서 열기

이 스킬 폴더(위에 표시된 Base directory)에 실행기 `mdview.mjs`와 뷰어 `viewer.html`이 있다. 실행기는 이 컴퓨터 안(127.0.0.1)에서만 접속되는 작은 서버를 띄우고 기본 브라우저에 뷰어를 연다. 이미 떠 있으면 그 서버를 다시 쓴다.

## 순서

1. 열 대상을 정한다.
   - 사용자가 경로를 주면 그대로 쓴다. 상대 경로는 현재 작업 폴더 기준이다.
   - 이름만 주거나("README", "설계 문서"), 이번 대화에서 만든 문서를 가리키면 Glob 등으로 찾는다. 후보가 하나면 그것을 열고, 여럿이면 사용자에게 고르게 묻고, 없으면 없다고 말한다.
   - 폴더를 열어 달라고 하면 폴더 경로를 쓴다. 뷰어의 작업 공간 트리로 열린다.
2. Bash로 실행기를 부른다. `--root`에는 현재 프로젝트 폴더(작업 폴더)를 넘겨, 문서 안의 상대 링크·이미지를 프로젝트 안에서 따라갈 수 있게 한다. 여러 파일은 한 번에 넘긴다(파일마다 탭 하나).

   ```bash
   node "<스킬 폴더>/mdview.mjs" --root "<작업 폴더>" "<파일 또는 폴더>"
   ```

   - 특정 위치를 보여 줄 때(방금 고친 절, 사용자가 물은 곳)는 경로 뒤에 `#제목`이나 `:줄`을 붙인다. 예: `"docs/보고서.md#3.2 결과"`, `"docs/보고서.md:120"`. 제목은 문서에 쓰인 글 그대로 써도 되고 GitHub식 id(`#32-결과`)도 된다. 줄은 1부터 센다. 그 이름의 파일이 실제로 있으면 위치로 보지 않는다.

3. 결과를 한 줄로 알린다. "브라우저의 MD Viewer에 열었습니다"처럼 무엇을 열었는지만 말하고, 문서 내용을 대화에 다시 옮기지 않는다.
   - 출력의 마지막 줄은 뷰어 주소다. 이 주소에는 실행기에 접속하는 토큰이 들어 있으므로 평소에는 대화에 옮기지 않는다.
   - `--no-open`으로 불렀거나 출력에 "브라우저를 열지 못했습니다"가 있을 때만 그 주소를 알려 주고 브라우저에서 직접 열라고 안내한다.

## 문제가 생기면

- `node`를 찾을 수 없다는 오류: Node.js 18 이상이 필요하다고 알리고 멈춘다.
- 브라우저가 뜨지 않는 환경(원격 접속, 헤드리스): `--no-open`을 붙여 다시 부르고 주소만 알려 준다.
- 실행기는 열린 뷰어가 없는 채로 10분이 지나면 스스로 끝난다. 바로 끄려면 `node "<스킬 폴더>/mdview.mjs" --stop`.
- 뷰어 탭이 이미 열려 있으면 새로 뜬 탭이 이전 탭의 문서를 넘겨받는다. 이전 탭은 "새 탭으로 옮겨짐" 안내만 남기므로 닫아도 된다. 단, 이전 탭에 저장하지 않은 변경이 있으면 그 탭은 변경을 잃지 않게 그대로 남는다. 그때는 이전 탭에서 저장하라고 알려 준다.

## 이미 열린 문서를 고친 뒤

- 뷰어에 열려 있는 문서를 Claude가 고치면 뷰어가 0.5초 안에 다시 읽고 바뀐 블록에 표시를 단다. 사용자는 Alt+F5(이전은 Shift+Alt+F5)나 상태 표시줄의 "바뀐 곳"으로 옮겨 다닌다. 그래서 새로 보이게 하려고 다시 열 필요는 없다.
- 고친 곳으로 바로 데려가고 싶을 때만 위치를 붙여 다시 연다(브라우저 새 탭이 이전 탭을 넘겨받고, 다른 문서의 보기 모드·위치는 이어진다).

## 사용자가 붙여 넣은 위치

사용자는 뷰어의 "위치 복사"(Ctrl+Alt+C)로 고칠 곳을 대화에 붙여 넣을 수 있다. 형식은 `경로:시작줄-끝줄`(줄 하나면 `경로:줄`) 한 줄과 그 아래 `> ` 인용 몇 줄이다. 줄은 1부터 세고 경로는 절대 경로다(독립 모드는 열린 폴더 기준 이름). 그 파일의 그 줄 범위를 읽어 요청을 처리한다. 인용은 어디인지 알아보는 데 쓰고, 파일 내용과 다르면 파일이 기준이다.

## 뷰어에서 고치기

- 열린 뷰어의 원문 보기(Ctrl+2)·분할 보기(Ctrl+3)에서 사용자가 문서를 고치고 Ctrl+S로 저장한다. 원래 인코딩·줄 끝을 지킨다.
- 실행기는 `--root`로 허용한 폴더(넘기지 않으면 파일이 든 git 저장소나 폴더) 안의 Markdown·텍스트 파일에만 쓴다. 다른 이름으로 저장도 그 안에서만 된다. 그래서 `--root`에는 현재 프로젝트 폴더를 넘긴다.
- 뷰어에 열린 파일을 Claude가 고치면 뷰어가 자동으로 다시 읽는다. 사용자가 그 파일을 뷰어에서 고치던 중(저장 전)이면 뷰어는 덮지 않고 "밖에서 파일이 바뀌었습니다" 띠를 띄운다. 사용자가 뷰어에서 고치는 중이라고 하면, 같은 파일을 고치기 전에 먼저 저장했는지 확인한다.

## 참고

- 설치: 배포 묶음의 `node mdview.mjs --install-skill`이 이 폴더(`~/.claude/skills/mdview`)를 만들고, 터미널에서 바로 쓸 수 있는 `mdview` 명령도 만든다.
- 실행기 없이 쓰려면 `viewer.html`을 브라우저로 바로 열고 파일을 끌어다 놓거나 Ctrl+O로 연다(독립 모드).
